Every source used, with a short note on what each was used for. The rule is simple: a value appears on this site only if one of these pages confirmed it.

The verification rule

  • Verified — an official page (the venue, the hotel, the operator, the government agency or the awarding body) states the value. The row links to that page.
  • Derived — arithmetic performed on values the official page published, with the arithmetic shown. Never presented as if the venue issued it.
  • Unverified — the value is left blank and carries a flag ID. No estimate, average or "typical" figure is substituted.
  • Third parties — review sites, blogs and aggregators were not used to fill cells. Where they surfaced a conflict, the conflict is recorded on the Flagged page instead.
