Highest impact first

If you only do three things

  1. S-01 — Lock the Feb 15–22, 2027 week. It is the cheapest window tested and it matches the 7-night cost basis.
  2. S-03 — Re-price MGM Grand, The Cosmopolitan and Bellagio. Three of the four hotels with a Michelin star on site have no verified price, which is the single biggest distortion in the ranking.
  3. S-02 — Get one itemised all-in quote from the top two hotels. That converts every "derived" figure into a real number.

Ways to improve the site itself

  • Total-cost calculator (S-08). Readers currently add hotel + restaurants + transit by hand. One clearly-labelled sum would let a decision be made in a minute.
  • Distance rings on the hotel page (S-11). A visual walking / bus / monorail ring per hotel would make the one-hour requirement obvious at a glance.
  • One recheck date for every live price (S-12). A single "prices rechecked on" banner keeps the site honest as rates drift.
  • Keep the current three-tier badge system. Verified / Derived / Unverified has proven the clearest way to show what is known without hiding what is not.

Data captured 2026-11-27 from official sources only. Hotel and restaurant prices are dynamic and will change. A cell is filled only when an official source confirmed it; everything else says Unverified and links to the flag that explains why.
