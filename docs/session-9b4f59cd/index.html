How to read this site. Verified means an official page confirmed it. Derived means it is the hotel's own published nightly rate multiplied by the number of nights, with the multiplication shown. Unverified means we could not confirm it and left it blank. Each blank carries a flag ID such as F-02 that explains the gap.

The four things this plan turns on

  1. Dates. Feb 15–22, 2027 was the cheapest week tested at every hotel that quoted several windows — and it matches the 7-night cost basis in the brief. Mar 15–22 was the most expensive (Caesars $310 vs $209 a night).
  2. Money. Only five hotels returned a price at all. The cheapest 2-queen room verified is Flamingo at $83 a night ($581 for 7 nights, before tax). Only Resorts World gave a true all-in total: $2,434.84.
  3. MICHELIN. Four starred restaurants exist, and three of them sit inside MGM Grand, Caesars Palace and The Cosmopolitan. The largest cluster (4) is at The Venetian, but none of those four is starred.
  4. Travel. There is no subway in Las Vegas. Restaurants are reachable by bus, monorail or car, and no official source publishes door-to-door minutes — so the one-hour rule is presented as route availability, not a minute count.

Recommended path

  • Stay 7 nights, Feb 15–22, 2027 — the cheapest week tested and it matches the 7-night cost basis.
  • If budget leads: Flamingo (2 queens, $581 derived) or South Point ($989 hotel-issued, 14-night option available).
  • If Michelin access leads: Caesars Palace (Guy Savoy on site, $1,463 derived) or MGM Grand (2 starred restaurants, price still missing).
  • If one all-in number matters most: Resorts World, $2,434.84 total.
  • Book the starred restaurants early — é by José Andrés releases tables three months ahead and seats nine.
