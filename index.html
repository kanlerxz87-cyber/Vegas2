About this site

Built as a static, mobile-friendly dashboard for the Vegas2 trip-planning project. Every value in a table carries a source link to an official site. If a value cannot be confirmed from an official source, it is left blank and flagged unverified. No values are inferred or filled in manually.

Sources used (Nov 27, 2026): official Michelin release + Visit Las Vegas (LVCVA) for guide statuses; official hotel/booking pages (Caesars, Venetian, Bellagio, ARIA, MGM Grand, Wynn, Cosmopolitan, Resorts World); official restaurant pages/menus; official activity pages (USBR, BLM, NV State Parks, Neon Museum, Bellagio, Caesars/LINQ, Fremont Street, Sphere, Cirque, Mandalay Bay); RTC + Monorail official sites. Full list on the Sources page; machine-readable record in data/session-c88d116c/verification.json.

Note: this repository also contains prior sessions' work under docs/, data/, scripts/, field-notes/, site/, legacy-dashboard/, and .github/workflows/. Those files are preserved and were not discarded during integration.
