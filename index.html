Key finding. All 24 Michelin-recognized restaurants are on or near the Las Vegas Strip / Downtown / Chinatown, so any Strip hotel puts every one of them within roughly 15–20 minutes by car, rideshare, bus, or the Las Vegas Monorail — well under the one-hour travel limit. Hotel choice should therefore be driven by price, room type (private bath, queen bed or larger), and amenity preference rather than Michelin proximity.

Data limitations. February 2027 real-time room rates are dynamic; The Venetian ($6,170.43 all-in), Caesars Palace ($226/nt + tax) and South Point ($919 + tax, fee-discrepancy flag) were captured from official sources for Feb 15–22, 2027. All other hotel prices, most activity prices, hours, and social-media links are left blank and flagged unverified until confirmed on an official source. Nothing here is inferred.

About this site

Built as a static, mobile-friendly dashboard for the Vegas2 trip-planning project. Every value in a table carries a source link to an official site. If a value cannot be confirmed from an official source, it is left blank and flagged unverified. No values are inferred or filled in manually.

Sources used: Visit Las Vegas (official LVCVA Michelin guide page), official restaurant sites (MGM Grand, Caesars, The Cosmopolitan, Wynn, The Venetian), official hotel booking pages (The Venetian, Caesars Palace). See each subpage and the Flagged for Review page for per-row sources.

Note: this repository also contains prior sessions' work under docs/, data/, scripts/, legacy-dashboard/, and .github/workflows/. Those files are preserved and were not discarded during integration. GitHub Pages serves the repository root (legacy source main /), which is why these root pages are the live site; files under docs/ are reachable at /docs/… paths.
